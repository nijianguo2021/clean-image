# 净图小站

浏览器本地图片修补 + 小红书公开笔记素材提取适配器。

图片修补使用边界引导插值，不使用生成模型，不能重建原本遮挡的细节。上传后需要涂抹选区；不宣称自动识别所有水印。支持原图对比、重置、继续修补和 PNG 下载。

链接提取需要 Netlify 函数后台。用此仓库部署到 Netlify 后，前台会探测同源服务。仅发布 public 到 GitHub Pages 时，链接提取明确显示未接通。

解析器只读取公开页面返回的数据，不执行页面脚本、不发送登录 Cookie，不绕过登录、验证码或平台限制。图片和视频适配器已做离线结构测试；未提供实际样本前，不能宣称平台实测通过。提取到的文件不保证无水印。

自动跟随的页面跳转和返回的媒体均限制到相关站点域名；不提供任意 URL 代理。链接只用于单次处理，不写入应用日志或数据库。

部署配置为 netlify.toml，无需 API key。推荐在上线公开链接提取之前设置平台配额与监控。
