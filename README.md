# 净图小站

本机图片修补。打开网页、选择图片、涂抹文字，点击「开始修复」后下载 PNG。不需要登录或 API key，图片和选区不离开浏览器。

使用 MI-GAN 官方 ONNX pipeline 和 ONNX Runtime Web 1.22.0 的单线程 WASM。首次下载约 28 MB 处理资源，通过本机 fflate 0.8.2 解压。公开静态资源支持 GitHub Pages 与固定版本 jsDelivr 备用线路，iPhone/iPad 优先使用备用线路，各条线路内容均进行大小及 SHA-256 校验。图片、选区不发送到这些服务。旧手机可能较慢或内存不足。长边最多 2400 像素，单张最大 30 MB。

黑字可选择「深色文字」，白字选择「浅色文字 / 水印」，颜色复杂时选择「整个涂抹区域」。尽量贴着文字涂抹，避免覆盖大量背景。生成的背景可能有差异，不保证完全无痕。选区外像素保持不变。支持取消、恢复原图、原图对比和继续修补。

本地测试：python -m http.server 8767 --bind 127.0.0.1 --directory public
发布目录：GitHub Pages 使用 docs，Netlify 使用 public。

模型：https://huggingface.co/andraniksargsyan/migan/blob/main/migan_pipeline_v2.onnx
项目：https://github.com/Picsart-AI-Research/MI-GAN
模型及运行库许可证分别见 models/LICENSE.txt、ort/LICENSE.txt 和 ort/ThirdPartyNotices.txt。
解压组件许可证：vendor/fflate-LICENSE.txt。

链接提取需要 Netlify 函数后台，GitHub Pages 上尚未接通。解析器只读取公开页面返回的数据，不执行页面脚本、不发送登录 Cookie，不绕过登录、验证码或平台限制。真实小红书样本跳转登录，不能宣称该链接提取成功。提取到的文件不保证无水印。

验证：浏览器实际载入用户样图、深色文字选区、执行 WASM 推理、检查门槛纹理与文字去除、成功下载 PNG。私有样图及结果不进入公开仓库。test.mjs 为历史插值及链接解析器测试，不能代替 AI 浏览器测试。

加载优化：文件完整性校验、下载进度、断线自动重试两次、可用时保存本机缓存；成功后复用工作线程和会话。资源错误与选区错误分别提示，并保留图片及选区以便重试。gzip 资源解压后与原版逐字节一致。
验证：node test-loader.cjs（下载失败/中断、超时、缓存损坏及不可用、资源哈希、gzip 解压、错误分类）；浏览器实际压缩资源加载、取消后重试、连续两次修复成功。尚未在用户报错的手机上复现。

精细修复：默认启用，在原有补全结果之后，仅针对选区内较窄且周围颜色稳定的缝隙参考原图进行颜色/线条细化；不扩大选区，不处理高频纹理或过宽的区域。保留快速模式供对比。无需新模型下载。验证：node test-quality.cjs（合成渐变/条纹改善、未选像素及透明度保持、粗糙背景与大孔洞保留原补全结果），以及黑字门槛样图与浅色水印图片浏览器实测。不能保证复杂图案完全恢复。

mobile1：针对手机报告的 wasm-01.bin / Fetch is aborted，增加备用线路、10 秒无数据超时和单次 30 秒下载上限；已完成且可缓存的分块无需重复下载。缓存打开、读取、写入均最多等待 1.2 秒，不可用则跳过。分开显示下载总进度、校验、解压及启动。启动超过 90 秒或工作线程 120 秒没有响应会明确报错并保留选区。测试覆盖挂起缓存、无视 AbortSignal 的请求、持续慢速流、线路切换、纯 JS 解压后哈希一致性。不能以桌面浏览器测试代替真实 iPhone 网络与设备验证。

浏览器验证 mobile1：在主资源目录强制返回 503 的本地测试站点，通过备用 CDN 完成所有分块下载、解压校验和真实图片推理；刷新后使用缓存再次修复成功。
